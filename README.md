# signsteps
ASL game-based language learning platform 

Demo Link: LINK COMING

# Unit 1
**Topic: Letters and Numbers**
**Game: Battleship**

Find the basics of ASL, learn to spell your own name, and beat the computer at battleship by signing the coordinates (e.g. sign the letter B, then the number 4).


# Unit 2
**Topic: Courtesies and Introductions**
**Game: Speed Signing**

Discover how to meet new people through ASL, make basic conversations, and get a high score by signing a given sentence as fast as you can!


# Unit 3
**Topic: Time and Descriptors**
**Game: Guess Who**

Mention concepts around past, present, future, form complex sentences, and describe unique character questions as you guess against the computer.
